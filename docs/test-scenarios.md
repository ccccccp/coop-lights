| 准入与退出     | 非房主不能开局、跨局命令拒绝、第五人不能加入、注销后旧会话失效                     |

## 浏览器 E2E（1 项通过）

启动已构建应用的临时 5198 服务，使用本机 Chrome 的两个隔离上下文，真实 UI 完成：登录 → 建房 → 加入 → 准备 → 开始 → 交替操作 → 第二人刷新 → 同局恢复 → 通关 → 保存 → 双方退出。

检查了双方棋盘可操作、成员更新、结算提示和无 pageerror；输出桌面与窄屏截图到 test-results。执行前运行 pnpm build，再执行 pnpm test:e2e。E2E 的测试用户和通关记录保留在专用游戏数据库。

## 人工快速检查

1. 打开 localhost:5178，普通浏览器与无痕窗口各登录一个昵称。
2. 使用房间号加入；检查在线状态及准备按钮。
3. 在开发面板填写种子 42，开局后交替点击或使用“下一步提示”。
4. 刷新其中一个页面，确认房间号、棋盘和贡献保持。
5. 点击断线重连测试，确认恢复后继续操作。
6. 结算显示记录已保存，准备下一关；离开房间后返回大厅。
